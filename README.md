# 🌈 Daily Mood Tracker

A responsive, animated, and interactive web application that allows users to track their daily mood with a visually appealing interface, smooth transitions, gradient-based background changes, and mood-based suggestions. Also includes a light/dark mode toggle for an enhanced user experience.

## 🧠 Features

- ✅ **Mood Selection** — Choose from predefined moods: 😊 Happy, 😢 Sad, 🤩 Excited, 😌 Calm.
- 🎨 **Animated Backgrounds** — Each mood triggers a smooth transition to a mood-specific **gradient** background.
- 💡 **Mood Suggestions** — Personalized tips displayed for each mood.
- 🌙 **Dark / Light Mode** — Easily toggle between light and dark themes with a single click.
- ⚙️ **Smooth Animations** — Animated headings, buttons, and suggestion fade-ins for an engaging UI.
- 📱 **Responsive Design** — Fully functional on mobile, tablet, and desktop.

## 💻 Tech Stack

- **HTML5** — Structured layout and semantic elements.
- **CSS3** — Flexbox, animations, gradients, transitions, media queries.
- **JavaScript (Vanilla)** — DOM manipulation, event handling, dark mode toggle.
